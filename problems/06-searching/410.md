# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
question says if we split the nums array into K subarrays what could be the maximum sum of the subarray.
and to find it we can have an idea that at max it could equal to or less than total sum of all elements in array or at least equal or higher from the biggest element in array


# Approach
<!-- Describe your approach to solving the problem. -->
so we have an idea that the number max could be between the above mentioned two numbers, so how about we do a search of which is right number from our range of `(min, max)` soon we will see that the range is in order , hence we should use binary search and find at what point the no. of subaarays can be made if possibly mid will be max nsum of sub.

int max(int a, int b){
    return (a > b)? a : b;
}
int splitArray(int* nums, int numsSize, int k) {
    int end = 0,start = 0;
        for(int i = 0; i < numsSize; i++){
            start = max(start, nums[i]);
            end += nums[i];
        }
        while(start < end){
            int mid = start + (end-start) /2;
            int pieces = 1;
            int sum = 0;
            for(int i = 0; i < numsSize; i++){
                if(mid < nums[i]+sum){
                    sum = nums[i];
                    pieces++;
                } else sum += nums[i];
            }
            if(pieces > k) start = mid +1;
            else end = mid;   
        }
        return end;
}
