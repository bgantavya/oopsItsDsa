[33. Search in Rotated Sorted Array
There is an integer array nums sorted in ascending order (with distinct values).
Prior to being passed to your function, nums is possibly rotated at an unknown pivot index k (1 <= k < nums.length) such that the resulting array is [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]] (0-indexed). For example, [0,1,2,4,5,6,7] might be rotated at pivot index 3 and become [4,5,6,7,0,1,2].
Given the array nums after the possible rotation and an integer target, return the index of target if it is in nums, or -1 if it is not in nums.
You must write an algorithm with O(log n) runtime complexity.

# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
ok firstly we have to accept the fact that rotated sorted array is also a type of concatenated two sorted arrays
which can be distinguished with the help of finding a peak element that could be referred to as last element of array 1 which lead to start of new array i.e. array 2 from pos(last element) +1 

# Approach
<!-- Describe your approach to solving the problem. -->
we can find the peak by a logic that the next element would be smaller if we're at peak
here instead of moving in serial we would go with binary search and find peak
then use binary search to find element in arr1 and then arr2
if not found in both we can still try going linear or return -1

int search(int* nums, int numsSize, int target) {
    int start = 0;
        int end = numsSize-1;
        if(end == 0){
            if(nums[0] == target) return 0;
            else return -1;
        } 
        while(start < end){
            int mid = start + (end-start) /2;
            if(nums[mid] > nums[mid+1]) end = mid;
            else start = mid +1;
        }
        if(nums[end] == target) return end;
        int peak = end;
        start = 0;
        end = peak;
        while(start <= end){
            int mid = start + (end-start) /2;
            if(nums[mid] > target) end = mid -1;
            else if(nums[mid] < target) start = mid +1;
            else return mid;
        }
        start = peak+1;
        end = numsSize -1;
        while(start <= end){
            int mid = start + (end-start) /2;
            if(nums[mid] > target) end = mid -1;
            else if(nums[mid] < target) start = mid +1;
            else return mid;
        }
        for(int i = 0; i < numsSize;i++) if(nums[i] == target) return i;
        return -1;
}
