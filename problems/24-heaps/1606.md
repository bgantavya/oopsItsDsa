## 💡 1. Intuition
- **Primary Challenge:** Simulating sequential request distribution across $K$ cyclic servers with dynamic release times while executing $O(\log K)$ successor queries for available servers $\ge (i \bmod K)$.
- **Key Observation:** Decoupling server state into two specialized data structures unlocks $O(N \log K)$ runtime:
  1. Min-Heap ordered by completion timestamp (`free_time`) for event-driven server release.
  2. Balanced Binary Search Tree (BBST) / `SortedList` ordered by `server_id` for $O(\log K)$ successor lookups $\ge (i \bmod K)$ with wrap-around fallback to `min(available)`.

---

## 🛠️ 2. Approach & Optimization
1. **Brute Force Approach:**
   - *Logic:* Maintain free-time array of size $K$. For request $i$, linearly scan indices from $(i \bmod K)$ to $(i + K - 1) \bmod K$ to locate the first free server.
   - *Drawback:* Results in **Time Limit Exceeded (TLE)** with $O(N \cdot K)$ worst-case time complexity ($N, K = 10^5 \implies \approx 10^{10}$ operations).

2. **Optimized Approach:**
   - *Logic:* Dual-structure event-driven simulation using a Min-Heap (`busy_servers`) and a BBST/SortedSet (`available_servers`).
   - *Mechanism:*
     - **Ejection Phase:** While `busy_servers.top().free_time` $\le \text{arrival}[i]$, pop `server_id` and insert into `available_servers`.
     - **Successor Lookup:** Query `available_servers` via `lower_bound(i % K)` (or `ceiling`).
     - **Wrap-around Selection:** If no candidate $\ge (i \bmod K)$ exists, fallback to `*available_servers.begin()`.
     - **State Mutation:** Remove assigned server $S$ from `available_servers`, increment `count[S]`, and push $( \text{arrival}[i] + \text{load}[i], S )$ to `busy_servers`.
     - **Drop Policy:** If `available_servers` is empty post-ejection, discard request $i$.

---

## ⚠️ Edge Cases Handled
- **All Servers Busy ($K$-Concurrence Limit):** Handled gracefully when `available_servers.empty()` evaluates to true; request is dropped in $O(1)$.
- **Single Server ($K = 1$):** Boundary constraint where successor queries degenerate to single-element checks with $O(1)$ heap pushes/pops.
- **Timestamp Overflow:** Arrival plus load ($\text{arrival}[i] + \text{load}[i] \le 2 \times 10^9$) stays within 32-bit signed boundaries, but modeled as 64-bit integers (`long long` / `int64_t`) to eliminate overflow risks in extended range systems.
- **Simultaneous Expiration Batches:** Multiple servers expiring before or at $\text{arrival}[i]$ are fully flushed from the min-heap in a single while-loop pass prior to allocation.

---

## ⏱️ Complexity Analysis
- **Time Complexity:** $$O(N \log K)$$
- *Explanation:* Processing $N$ requests. Each request triggers amortized $O(\log K)$ heap operations (at most $N$ pushes/pops overall) and 1 BBST search/erasure of complexity $O(\log K)$.
- **Space Complexity:** $$O(K)$$
- *Explanation:* Min-heap stores at most $K$ busy elements, BBST stores at most $K$ free server IDs, and the request counter array uses $O(K)$ auxiliary memory.

## 💻 Code Solutions

```Cpp []
class Solution {
    struct Job {
        int at;
        int server;
        auto operator<=>(const Job&) const = default;
    };
    template <class T> using MinHeap = priority_queue<T, vector<T>, greater<>>;


public:
    vector<int> busiestServers(int k, vector<int>& arrival, vector<int>& load) {
        vector<int> server(k);
        iota(server.begin(), server.end(), 0);
        MinHeap<int> free(greater<>{}, std::move(server));
        MinHeap<Job> busy;
        vector<int> handled(k);
        for (int i = 0; i < arrival.size(); ++i) {
            while (!busy.empty() && busy.top().at <= arrival[i]) {
                int x = busy.top().server;
                busy.pop();
                free.push(i + (x - i % k + k) % k);
            } if (free.empty()) continue;
            int x = free.top() % k;
            free.pop();
            busy.push({arrival[i] + load[i], x});
            ++handled[x];
        } int most = ranges::max(handled);
        vector<int> result;
        for(int i = 0; i < k; ++i) if(handled[i] == most) result.push_back(i);
        return result;
    }
};
```
