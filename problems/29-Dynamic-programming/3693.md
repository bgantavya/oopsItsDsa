## 💡 1. Intuition
- **Primary Challenge:** Finding the minimum cost path to reach step $n$ from step $0$ with restricted jump lengths ($\Delta \in \{1, 2, 3\}$) and quadratic distance-based penalties.
- **Key Observation:** Optimal substructure property applies. Let $f[i]$ be the minimum cost to reach step $i$. Since each state $i$ can only be reached from predecessors $i-3$, $i-2$, or $i-1$, the recurrence relation evaluates the minimum over a constant-sized sliding window of size 3.

---

## 🛠️ 2. Approach & Optimization
1. **Brute Force Approach:**
   - *Logic:* Recursively explore all combinations of jumps ($+1, +2, +3$) from step $0$ to $n$.
   - *Drawback:* Results in **Time Limit Exceeded (TLE)** with $O(3^N)$ exponential time complexity due to overlapping subproblems.
2. **Optimized Approach:**
   - *Logic:* Bottom-up dynamic programming tabulation with state initialization $f[0] = 0$ and $f[i] = \infty$ for $i > 0$.
   - *Mechanism:* For each step $i \in [1, n]$, iterate through predecessor states $j \in [\max(0, i-3), i-1]$ to compute:
     $$f[i] = \min_{j = i-3}^{i-1} \left( f[j] + \text{costs}[i-1] + (i - j)^2 \right)$$

---

## ⚠️ Edge Cases Handled
- **Minimal Constraints ($N = 1$):** Evaluates single jump from $0 \to 1$ correctly under $O(1)$ operations.
- **Out-of-Bounds Predecessors:** Constrained lower index via $\max(0, i-3)$ to prevent negative array accesses for steps $1, 2$.
- **Integer Overflow:** Initialized state array with `INF = INT_MAX / 2` to prevent arithmetic overflow during addition operations.

---

## ⏱️ Complexity Analysis
- **Time Complexity:** $$O(N)$$
- *Explanation:* A single linear pass from $1$ to $N$ with an inner loop bound capped at a constant maximum size of $3$ ($O(3N) \implies O(N)$).
- **Space Complexity:** $$O(N)$$
- *Explanation:* Auxiliary 1D DP array of size $N + 1$ required to store minimum cost states. (Space can be optimized to $O(1)$ by keeping only the last 3 states).

## 💻 Code Solutions

```Cpp []
class Solution {
public:
    int climbStairsII(int n, vector<int>& costs) {
        vector<long long> dp(n + 1, 1e18);
        dp[0] = 0;
        for (int i = 1; i <= n; ++i) {
            for (int j = max(0, i - 3); j < i; ++j) {
                long long cost = dp[j] + costs[i - 1] + (long long)(i - j) * (i - j);
                dp[i] = min(dp[i], cost);
            }
        }
        return dp[n];
    }
};
```
