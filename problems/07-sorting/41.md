[
    41. First Missing Positive
Given an unsorted integer array nums. Return the smallest positive integer that is not present in nums.
You must implement an algorithm that runs in O(n) time and uses O(1) auxiliary space.

# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
we have to just return the first missing positive so lets try storing elements in ways such that nums[i] = i+1 

# Approach
<!-- Describe your approach to solving the problem. -->
wherever after sorting this patters break while iterating we will return it else we do return n+1 considering we have all elements at right index i = [0...n] nums = [1...n+1]

```C []
int firstMissingPositive(int* nums, int numsSize) {
    int i = 0;
        int n = numsSize;
        while(i < n){
            if(nums[i] <= n && nums[i] > 0 && nums[i] != nums[nums[i]-1]){
                int correct = nums[i] -1;
                int temp = nums[correct];
                nums[correct] = nums[i];
                nums[i] = temp;
            }
            else i++;
        }
        for(i = 0; i < n; i++){
            if(i+1 != nums[i]) return i+1;
        }
        return n+1;
}
```
