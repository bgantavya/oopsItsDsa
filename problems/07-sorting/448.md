

# Problem
<!-- Problem statement with number here -->
[448. Find All Numbers Disappeared in an Array
Given an array nums of n integers where nums[i] is in the range [1, n], return an array of all the integers in the range [1, n] that do not appear in nums.
](
https://leetcode.com/problems/find-all-numbers-disappeared-in-an-array/description/)
<!-- Link:  -->

---

# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
since we have to find duplicate number where array nums of length n can have elements till n at indexes
so we can use cyclic sort to arrange then we can find the duplicates

# Approach
<!-- Describe your approach to solving the problem. -->
when we sort we put elements at their correct indexes which would be i + 1 = nums[i]
if there is any inconsistency we will store that element considering we did sort first
at last we will return an ArrayList containing all duplicates

/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* findDisappearedNumbers(int* nums, int numsSize, int* returnSize) {
    int i = 0;
    while(i < numsSize){
        int correct = nums[i] -1;
        if(correct < numsSize && nums[i] != nums[correct]){
            int temp = nums[correct];
            nums[correct] = nums[i];
            nums[i] = temp;
        }
        else i++;
    }
    int count = 0;
    int* res = (int*)malloc(sizeof(int)*numsSize);
    for(i = 0; i < numsSize; i++){
        if(nums[i] != i+1) res[count++] = i+1;
    }
    *returnSize = count;
    return res;
}
