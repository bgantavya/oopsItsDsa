# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
since we have to find duplicate number where array nums of length n can have elements till n at indexes
so we can use cyclic sort to arrange then we can find the duplicate

# Approach
<!-- Describe your approach to solving the problem. -->
when we sort we put elements at their correct indexes which would be i + 1 = nums[i]
if there is any inconsistency we will store that element considering we did sort first
and at last we will return duplicate num stored ArrayList

int* findDuplicates(int* nums, int numsSize, int* returnSize) {
    int i = 0; 
        while(i < numsSize){
            int correct = nums[i] -1;
            if(correct <numsSize && nums[correct] != nums[i]){
                int temp = nums[correct];
                nums[correct] = nums[i];
                nums[i] = temp;
            }
            else i++;
        }
        int count = 0;
        int* res = (int*)malloc(numsSize *sizeof(int));
        for(i = 0; i < numsSize; i++) if(nums[i] != i+1) res[count++] = nums[i];
        *returnSize = count;
        return res;
}
