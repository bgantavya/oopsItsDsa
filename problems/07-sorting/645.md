[   645. Set Mismatch

You are given an integer array nums representing the data status of this set after the error.
Find the number that occurs twice and the number that is missing and return them in the form of an array.

# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
since we have to find duplicate number where array nums of length n can have elements till n at indexes
so we can use cyclic sort to arrange then we can find the duplicate

# Approach
<!-- Describe your approach to solving the problem. -->
when we sort we put elements at their correct indexes which would be i + 1 = nums[i]
if there is any inconsistency we will return that element considering we did sort first
with the element that should be there

/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* findErrorNums(int* nums, int numsSize, int* returnSize) {
    int n = numsSize;
    int i = 0;

    while (i < n) {
        int correct = nums[i] - 1;
        if (correct < n && nums[correct] != nums[i]) {
            int temp = nums[correct];
            nums[correct] = nums[i];
            nums[i] = temp;
        } else
            i++;
    }

    int* res = (int*)malloc(2 * sizeof(int));
    *returnSize = 2;

    for (i = 0; i < n; i++) {
        if (nums[i] != i + 1) {
            res[0] = nums[i];
            res[1] = i + 1;
            return res;
        }
    }

    res[0] = -1;
    res[1] = -1;
    return res;
}
